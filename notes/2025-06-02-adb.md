## ABD Basic Commands

### List the devices

```{code-block} console
$ adb devices
```

### Hang the system

```{code-block} console
$ adb shell
RMX1807:/ $ am hang
```

### Activity manager (`am`)

See [ADB IntentSpec](https://developer.android.com/tools/adb#IntentSpec) for options.

| Option                  | Description                                         |
| ----------------------- | --------------------------------------------------- |
| `-a`                    | Action (e.g., `android.intent.action.VIEW`)         |
| `-d`                    | Data URI (e.g., `-d http://example.com`)            |
| `-t`                    | MIME type (e.g., `-t text/plain`)                   |
| `-c`                    | Category (e.g., `android.intent.category.LAUNCHER`) |
| `-n`                    | Component name (pkg/.Activity)                      |
| `-e`                    | Add string extra (`-e key value`)                   |
| `--ez`                  | Add boolean extra (`--ez key true`)                 |
| `--esn`                 | Add null extra                                      |
| `--activity-clear-top`  | Clears existing activity on top                     |
| `--activity-single-top` | Reuses existing instance if already on top          |

#### 1. Open an Intent
```{code-block} console
$ adb shell
RMX1807:/ $ am start -n com.intsig.camscanner/.CaptureActivity
```
```{code-block} console
RMX1807:/ $ am start -a android.intent.action.VIEW
```

#### 2. Open Camera

```{code-block} console
$ adb shell
RMX1807:/ $ am start -a android.media.action.IMAGE_CAPTURE
```

#### 5. Starting Chrome

```{code-block} console
RMX1807:/ $ am start -n com.android.chrome/com.google.android.apps.chrome.Main
```

```{code-block} console

```

### Taking a screenshot

```{code-block} console
RMX1807:/ $ screencap /sdcard/screen.png
```

And the screenshot is located in `Phone/screen.png`.

### Open a Camera and click a picture

```{code-block} console
RMX1807:/ $ am start -a android.media.action.IMAGE_CAPTURE
```

This opens the camera, but doesn’t trigger the capture. To simulate a tap:

```{code-block} console
RMX1807:/ $ wm size
Physical size: 1080x2340
RMX1807:/ $ input tap 540 512
```
